# Mars Yard Gem

Author: Azmyin Md. Kamal
Date: 09/09/2024
Version: 1.0

This is the Mars Yard gem, an Asset only gem based on NASA JPL's [Mars Yard](https://www-robotics.jpl.nasa.gov/how-we-do-it/facilities/marsyard-iii/) rover testing fascility. It was created as part of submission for the NASA Space ROS Sim Summer Sprint Challenge 2024, Issue [#181](https://github.com/space-ros/docker/issues/181). Comes with a number of custom prefabs and phyxmaterials.
